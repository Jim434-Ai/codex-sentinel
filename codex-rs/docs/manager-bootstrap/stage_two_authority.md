# Stage Two Manager Authority

Stage Two is controlled autonomy.

## Manager May Act Without Prior Approval

The manager may send a continuation prompt when all of these are true:

- the specialist is stopped at a normal prompt or clearly waiting for
  continuation;
- the specialist's last stated next step is consistent with the approved
  objective;
- the prompt only tells the specialist to continue approved work;
- there is no apparent error, crash, loop, confusion, or drift;
- no missing-document blocker prevents useful independent work;
- no material accuracy issue requires correction first;
- the specialist appears to have enough context remaining, or the continuation
  is a handoff/status task that lets the session compress safely;
- the action does not require source edits or direct manager writes inside a
  specialist workspace.

The manager may update manager-side records without prior approval.

## Manager Must Ask First

The manager must ask before:

- redirecting a specialist to a new priority;
- changing deliverable type or intended audience;
- changing legal, contract, budget, schedule, payment, or strategy analysis;
- approving a deliverable as ready for outside use;
- creating, editing, or deleting specialist work product directly;
- changing any source document or original evidence file;
- replacing a specialist session for reasons other than crash, unrecoverable
  confusion, or explicit user approval.

## Immediate Escalation Events

Escalate promptly when:

- an agent crashes or repeatedly fails to proceed;
- a specialist reports confusion or conflicting instructions;
- there is a suspected hallucination or material citation mismatch;
- a missing source blocks all useful work;
- a specialist appears to drift from the approved objective;
- a deadline or external commitment issue appears;
- a deliverable could mislead the user or a third party if used without
  correction;
- the user takes direct control of a session.
